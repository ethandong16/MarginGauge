How Offsite Ads Change Your Etsy Target Price

An Offsite Ads fee is a percentage of an attributed order, so the listing price that reaches your profit target changes with the applicable 12% or 15% tier. Calculate the scenarios separately instead of adding a generic buffer.

If an Etsy order is attributed to Offsite Ads, the fee is an additional order debit. For a fixed profit target, that debit raises the minimum listing price. In the supported US model, the current scenarios are 15% or 12% of eligible seller revenue, capped at $100 per order.

1. The short answer: price for the order outcome you can receive

A listing that reaches a $10 contribution target without Offsite Ads may miss that target when Etsy attributes the order to a 15% or 12% Offsite Ads tier. The correct price depends on the rest of the order: product cost, buyer-paid shipping, packaging, actual fulfillment, tax scenario, and any other entered variable costs.

Do not treat Offsite Ads as the same thing as Etsy Ads. Offsite Ads is an attributed-order fee. Etsy Ads spend is a seller-entered marketing allocation and belongs in a separate line in the calculator.

Confirm the shop tier first. The calculator does not infer 12% eligibility from order value. Select 12% only after confirming the shop's reduced tier in Etsy, and use 15% for the applicable 15% scenario.

2. Set one fixed cost model before comparing scenarios

Use one physical item with $4.50 product cost, $10.00 buyer-paid shipping, $10.00 actual shipping, and $5.00 packaging. There is no discount, personalization, gift wrap, sales tax, Etsy Ads allocation, or Texas seller-fee tax. The target is $10.00 contribution profit.

Only the attribution choice changes between scenarios. This isolates the price effect of the Offsite Ads line and prevents a shipping or labor change from being mistaken for an advertising-fee effect.

3. The minimum price rises from $23.09 to $29.67

The Target Price engine calculates the minimum pre-discount unit listing price that reaches the same $10.00 profit target under each supported attribution outcome.

ScenarioMinimum priceOffsite Ads feeContribution profitMargin
No attributed program$23.09$0.00$10.0034.27%
Offsite Ads, 15%$29.67$5.95$10.0039.96%
Offsite Ads, 12%$28.15$4.58$10.0035.52%

The 15% scenario requires $6.58 more listing price than the no-attribution scenario. The 12% scenario requires $5.06 more. These are minimum thresholds for this cost model, not recommendations about market demand or buyer willingness to pay.

4. The rate tier is a seller-specific input

Etsy's published Offsite Ads guidance uses a 15% rate for shops below its stated sales threshold and a reduced 12% rate after the threshold is reached. Participation requirements and the shop's status determine which scenario applies. The calculator requires confirmation for 12% so an order is not priced against an assumed tier.

For an existing order, inspect the order and Payment Account records. For a future listing, stress-test both rates when you are unsure which attributed outcome your shop could receive. The 12% result is lower than the 15% result, but it is not automatically available to every shop.

5. The $100 cap matters on higher-value orders

Offsite Ads is capped at $100 per order in the supported model. At 15%, the uncapped fee reaches $100 at $666.67 of eligible revenue. At 12%, it reaches the cap at $833.33. Above those thresholds, the percentage no longer increases the fee for that order.

Do not apply the cap to a shop's total monthly advertising cost, and do not spread an order cap across multiple orders. It is an order-level fee cap. The actual eligible revenue base and Etsy's attribution record control the final debit.

6. Use Target Price to test the fee explicitly

Open the Etsy Profit Calculator, choose Target price, enter the product and fulfillment costs, set a profit or margin target, and select the attribution scenario. Keep all non-attribution inputs fixed while comparing results.

  • Use no attributed program to see the ordinary price floor.
  • Use Offsite Ads 15% for the applicable 15% tier.
  • Use Offsite Ads 12% only after confirming eligibility.
  • Enter Etsy Ads spend separately if you allocate it to the order.
  • Review the result before a seller-funded discount: the target-price output is the pre-discount listing price.

For the underlying fee rules, read Etsy Offsite Ads Fees: 12%, 15%, and the $100 Cap. For seller-driven attribution, compare Share & Save vs Offsite Ads. For a complete pricing workflow, read How to Price Etsy Products for Profit.
